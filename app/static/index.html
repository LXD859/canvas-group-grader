01

连接 Canvas

Token 只保存在本次服务内存中。
如何获取 Token？

在 Canvas「账户 → 设置」中查找「新建访问令牌」。请使用拥有目标课程评分权限的账号。如果学校未开放此入口，请联系课程负责人或 Canvas 管理员。无需将 Token 发给任何人。

02

选择作业与批改表

每行一个小组，每列一道题。空白题目不扣分；有问题填写 -1.5, Missing justification.

03

核对并提交

仅勾选已批改的小组。勾选后，各题全空的小组将获得满分。已有成绩或评语需要修改时，请同时勾选「确认更新」。

提交后的可见性遵循 Canvas 当前成绩发布政策；自动发布的作业可能立即向学生显示成绩和评语。
